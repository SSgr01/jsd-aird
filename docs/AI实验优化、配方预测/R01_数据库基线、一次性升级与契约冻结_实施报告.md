### 2.2 用户提供的测试环境Schema快照

核查目录：C:/Users/Ssgr/Desktop/jsd_ai_schema_20260912/。

快照包含30张MDM/RND表。当前Repository直接依赖其中28张；mdm.customer_requirement_project和rnd.experiment_report是快照中的历史附加表，不纳入新环境必需基线，也不在R01删除。

发现两类需要在正式演练前处理的差异：

1. 快照的rnd.experiment_outbox缺少当前任务恢复机制需要的attempts和available_at。预检会将这类半套结构判为INCOMPATIBLE_FOUNDATION，不会使用IF NOT EXISTS掩盖。
2. 快照的mdm.project.organization_id为必填列，而当前ProjectMapper.insert未写入该列。这是现有Schema与Repository的真实差异，不能通过R01脚本猜测租户值。正式升级前需先确定项目主数据的组织写入规则。

测试快照页眉显示PostgreSQL 15.10，低于R01固定的16～18运行范围。该结论仅来自Schema快照；由于在线连接在认证前关闭，本轮未读取测试环境的表数据或Flyway历史。

## 3. 数据库交付

| 交付 | 文件 | 作用 |
|---|---|---|

| 证据保全 | db/r01/preserve_legacy_ai_evidence.sql | 幂等复制旧运行、候选、模型上下文到实验侧不可变证据 |
| 删除盘点 | db/r01/legacy_ai_deletion_inventory.sql | 只读列出R10删除顺序、外键、对象存储引用和证据阻断 |
| 事实演练数据 | db/r01/rehearsal_fact_fixture.sql | 构造明确标识的文件、审计、导入、材料、项目、实验及旧AI实验关联 |
| 约束演练 | db/r01/constraint_rehearsal.sql | 在事务内验证租户外键、唯一ACTIVE和不可变边界，结束时回滚测试行 |
| 统一入口 | scripts/db-r01-*.ps1/.sh | 预检、显式升级、完整逻辑备份、空临时库恢复及摘要比对 |

升级入口执行顺序固定为：

    校验目标库身份和PostgreSQL 16～18
    → Flyway迁移/校验到V52
    → 基线预检
    → EMPTY时执行28表基础DDL；INCOMPATIBLE时停止
    → Flyway迁移V53～V57
    → 幂等保全旧AI实验来源证据
    → 复查基线、保护清单和悬空引用

V57新增33张表，其中28张位于ai、3张位于data、1张位于mdm、1张位于rnd。主要约束包括组织复合外键、配置与事实哈希、JSON类型校验、稳定分页索引、业务幂等键、每组织每Y唯一ACTIVE模型和已冻结/已发布内容的数据库不可变触发器。

## 4. 契约交付

### 4.1 公共业务契约

ai-rnd.v1.openapi.yaml冻结42条路径、47个操作，服务器前缀为/api/v1/ai/rnd。契约覆盖建模设置、资格与审查、模型管理、性能预测、配方预测和实验优化，规定分页、请求ID、幂等键、乐观锁、结构化错误和逐Y成功/阻断结果。

Java和TypeScript类型均使用同一results联合结构。阻断项没有预测字段；连续、序数、二分类和多分类分别表达。权限过滤器逐操作对照OpenAPI校验，旧ai.use和ai.model.manage路由保持原映射，不自动授予新权限。

V57登记10项新权限：ai.modeling.read、ai.model.read、ai.performance.predict、ai.formula.predict、ai.experiment.optimize、ai.modeling.manage、ai.data.review、ai.model.publish、ai.training.operate、ai.config.manage。

### 4.2 Java/Python内部契约

contracts_v2.py是独立Pydantic源，不导入V1类型。它冻结validate、validation-folds、train、score和recommend载荷；每次请求显式携带Y定义、输入方案、材料字典、预处理、训练策略及版本哈希。R01没有注册/internal/v2路由，也没有切换现有V1客户端。

黄金样例保留98.8%的原始配方总量，并覆盖60°光泽连续值、硬度序数、UV表干二分类和外观多分类；四个Y可绑定四个不同模型版本。生成Schema的SHA-256为：
