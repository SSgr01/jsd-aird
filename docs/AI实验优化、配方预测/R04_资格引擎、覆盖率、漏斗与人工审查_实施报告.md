## 1. 本轮范围

本轮实现按 Y 版本、冻结输入方案、来源映射、材料字典和已发布训练策略计算训练资格，提供三态结果、原因、字段覆盖率、资格漏斗、样本详情和人工审查入口。

本轮没有创建 Snapshot、训练任务、模型制品、正式模型或预测结果，也没有修改 V57。数据库结构使用新增的 V58 迁移。

## 2. 已完成的实现

### 2.1 数据库

新增 `V58__ai_rnd_eligibility_engine.sql`，包括：

- `ai.eligibility_evaluation_run`：记录目标版本、输入方案、规则指纹、异步任务、运行状态、进度和统计。

### 2.3 规则行为

已落实的门禁和表达：

- 缺少必需 X：`EXCLUDED / MISSING_REQUIRED_X`。
- 未知材料：`REVIEW_REQUIRED / UNKNOWN_MATERIAL`。
- 目标语义不匹配：`EXCLUDED / TARGET_SEMANTIC_MISMATCH`。
- 配方比例或基准无法解析：`EXCLUDED / FORMULA_BASIS_UNRESOLVED`。
- 文本目标、无效目标值和实验后字段不会冒充普通连续值或实验前 X。
- 98.8% 这类已明确记录的比例保留原值，只产生非阻断警告；不会自动补齐或归一化。
- 多个原因被完整保存，主原因按照固定顺序展示，漏斗阶段不重复扣减。
- 没有冻结方案或已发布策略时返回配置未就绪，页面不展示伪造的样本统计。

### 2.4 页面

`/assistant/modeling-settings` 的 Y 详情“训练数据与输入 X”区域现在提供：

- 样本详情抽屉，展示逻辑样本、权威来源、事实版本、配方、工艺/条件、测试结果、来源坐标和实验/数据中心引用。

### 5.1 本轮继续修正

- 资格 Worker 执行时改为读取运行记录冻结的 Y、输入方案、来源映射、材料字典和策略版本，不再跟随目标当前指针，避免排队期间配置变化污染旧运行。
- 重算请求接入配置命令回执：同一 `Idempotency-Key` 同载荷返回原结果，载荷变化返回幂等冲突；并修正并发入队时返回实际已有任务 ID 的竞态。
- 自动触发重算在复用已有异步任务时不再重复创建运行记录，避免同一事实高水位产生多个资格运行。
- 规则评估补齐 Y 多匹配、文本/下界/区间观测阻断、未知材料待审查、主原因按设计顺序稳定选择；样本空对象也按缺失处理。
- 覆盖率分母改为当前运行中目标值有效的样本，字段没有缺失时不再显示虚假的缺失原因；审查决定要求理由，关闭的审查项不能重复决定，材料重映射必须带材料 ID。
- 漏斗阶段改为累计单调计算：来源观察→去重样本→Y 匹配→Y 有效→X 齐全→材料/审查通过→可训练，后续阶段不会因为其他门禁通过而反向高于前一阶段；资格 upsert 同时增加运行创建顺序保护，旧运行不能覆盖较新运行。
- 新增规则单测后，`EligibilityRuleEvaluatorTest` 为 7/7；Web 全量 typecheck 与生产构建均通过。

上述两项并发/漏斗修正已通过 Java 编译和定向测试；浏览器中已有的历史运行数据保持其原始快照，部署后重新评估才会生成采用新漏斗顺序的运行记录。
- 本机 `.env` 库已执行 V58；为避免重启时产生 Flyway 校验和漂移，V58 文件保持已执行内容，使用 Flyway `ChecksumCalculator` 核对为 `446671603`，本轮新增行为均落在 Java 逻辑中。
