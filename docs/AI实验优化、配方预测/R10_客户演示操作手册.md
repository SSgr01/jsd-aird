# AI研发模块客户演示操作手册

## 演示定位

本次演示展示的是从实验数据进入系统，到建模配置、训练、预测、配方搜索和实验反馈的完整产品链路。演示使用隔离环境中的合成数据和合成模型，重点证明页面流程、数据追溯、门禁和结果表达，不把合成模型的结果当作客户生产模型精度承诺。

演示前确认浏览器打开的是本地演示环境：`http://127.0.0.1:5175`。不要在客户面前切换到测试环境数据库，也不要执行数据库迁移或重启 Worker。

## 演示前检查

1. 打开四个页面标签：数据中心上传、实验记录本上传、模型中心、性能预测。配方预测和实验优化在需要时从左侧菜单进入。
2. 确认模型中心“模型列表”能看到使用中的测试模型，建模设置能看到 Y/X 和输入方案。
3. 确认 Python、API、Worker 和 Web 都已经运行。演示当天只做浏览器操作，服务异常时先刷新页面，不要在客户面前重新启动服务。
4. 准备两份客户模板文件：应用测试报告和综合测试报告。每份文件应包含多条记录，避免演示成只有一条数据。

## 推荐演示顺序

### 1. 从数据中心导入实验数据

进入 `/data/upload`，上传应用测试报告模板。选择已经发布的客户模板，打开字段映射确认页，展示原始 Sheet、字段位置和映射结果，然后确认提交。

可以这样向客户说明：

> 文件先保留为原始文件，系统只在确认字段对应关系后形成正式数据。原始值、修改值和文件位置都会保留，后面模型使用的每个结果都能追溯回这里。

确认后打开导入详情，确认页面显示多条记录、配方、工艺条件和测试结果。再用综合测试报告重复一次，展示不同文件可以进入同一套标准事实。

### 2. 从实验记录本导入并完成实验草稿

进入 `/experiments/upload`，选择按客户模板导入，上传另一份客户模板。进入右侧字段映射工作台，确认后进入实验草稿。

在 Univer 原文件工作台中展示 Sheet、原始表格和实验字段，修改一个条件或结果并保存草稿。随后执行实验审核完成。

对客户说明：

> 数据中心确认的是正式数据版本；实验记录本保存的是实验过程、审核和修订。两边可以互相看到来源，但不会互相复制或覆盖所有权。实验完成后，才进入 AI 的统一事实。

### 3. 在模型中心配置 Y、X 和输入方案

进入 `/assistant/model-center?tab=settings`。

先打开一个已有目标，例如 60°光泽或 500g 钢丝绒耐磨次数，展示：

- Y 的结果类型、单位、测试方法和测试阶段；
- 数据来源中数据中心和实验记录本的覆盖；
- 输入字段库 X；
- 当前训练输入方案和资格状态。

再切换到输入字段库 X，说明配方、基材、温度、UV 能量等字段如何成为模型输入。演示时不要现场新建复杂目标，先展示已准备好的目标；客户问到新增 Y 时，再说明流程是“定义 Y → 确认来源映射 → 选择 X → 冻结输入方案 → 重新评估历史事实”。

切换到 `/assistant/model-center?tab=models`，展示训练任务、候选模型、算法、使用中模型和历史版本。可以打开详情说明“候选模型通过验证后仍需人工启用”。

### 4. 演示多类型模型训练结果

模型中心中准备好的目标覆盖四种结果表达：

- 60°光泽：连续值；
- 铅笔硬度：序数等级；
- UV表干：二分类；
- 外观等级：多分类。

重点演示页面如何按类型展示结果，不需要向客户解释 UUID、Snapshot、Worker 或 JSON。客户询问模型精度时说明：

> 今天使用的是隔离演示数据，正式模型需要客户真实数据、SOP、类别定义、误差门槛和适用域确认后才能启用。

### 5. 演示正向性能预测

进入 `/assistant/performance-prediction`：

1. 选择 60°光泽、UV表干、铅笔硬度和外观等级；
2. 填写基材、温度、UV 条件和配方材料实际比例；
3. 确认配方完整，点击“开始性能预测”；
4. 展示右侧四种类型的结果：连续值、等级、类别概率和多分类概率分布。

说明页面会对每个 Y 单独检查模型、输入、材料和适用范围，因此一个目标被阻断时，其他满足条件的目标仍可以返回结果。然后可选演示一个没有正式模型的目标，展示清晰的“无法预测”原因。

### 6. 演示配方逆向预测

进入 `/assistant/formula-prediction`：

1. 选择有 ACTIVE 测试模型的性能目标；
2. 设置目标值或等级及最低概率；
3. 设置材料固定值、可变范围和目标总量 100%；
4. 点击“开始搜索”；
5. 展示最多四张候选配方卡，确认每组实际比例合计准确。

可将目标总量改为 98.8% 再搜索，说明系统保留用户确认的实际总量，不会自动补齐或归一化。需要展示无解时，使用明显超出适用范围的目标，页面会显示没有可行候选及调整建议；不要把无解解释成系统故障。

### 7. 演示实验优化和实验反馈

进入 `/assistant/experiment-optimization`：

1. 选择已完成实验作为基线；
2. 展示当前实际结果和已有预测/实测对照；
3. 选择优化目标和允许调整的材料或实验前条件；
4. 点击生成建议，展示对照、保守改进、多目标平衡和受控探索四类方案；
5. 选中一个方案，创建实验草稿并选择客户实验模板；
6. 打开实验本，展示客户原始 Sheet 和可编辑草稿；
7. 在实验本补录实际结果并完成实验；
8. 回到优化运行页，展示逐 Y 的预测值、实测值、误差和可比性。

对客户说明：

> AI 只提出下一轮实验建议，用户选择后才会创建草稿。实测结果必须在实验本中录入并完成审核，系统再把结果回灌到统一事实和反馈记录。

## 客户现场常见问题

- **为什么不能直接预测？** 目标可能没有正式模型、缺少必需输入、材料未知或超出适用范围。页面会按目标给出原因。
- **配方必须合计 100% 吗？** 不必须。100%、98.8%或其他实际合计都可以，但比例必须明确；空白表示未知，明确填 0 才表示未使用。
- **预测结果是不是生产结论？** 本次是隔离演示。生产模型必须经过真实数据、SOP、阈值、材料和适用域验收。
- **为什么候选少于 4 个？** 系统只展示真实可行方案，不复制方案凑数量。

## 演示异常处理

页面显示加载中时先等待 5～10 秒并刷新；预测或搜索失败时展示页面中的结构化原因，不要反复点击提交。若服务确实停止，暂停演示并在客户离开后恢复服务，再从模型中心和运行详情继续。

## 演示结束时要展示的结果

最后回到模型中心模型列表，展示模型版本和训练数据；再回到实验优化运行，展示候选、实验草稿和逐 Y 反馈。明确说明：演示链路已经走通，生产模型启用仍以客户真实资料和正式验收为准。
