# 杰事达研发系统操作手册

版本：2026-10-15.1

本手册为根据当前系统页面与代码整理的初稿。操作入口、按钮名称和技术限制来自当前实现；业务判断、职责和验收标准未得到正式文档确认时标记为“待业务核对”。后续正式文档逐章核对合并后，随系统版本发布。

账号权限和资料的数据范围决定可见功能。具体操作前请核对页面提示，不将任务提交成功等同于业务数据已经确认。

<!-- section: navigation -->
## 找到功能与使用操作助手

入口：登录后的工作台和左侧功能菜单。

1. 在左侧菜单选择需要使用的业务模块，再进入相应子页面。
2. 点击右下角“操作助手”，输入你的操作目标，例如“怎样导入实验记录”。
3. 按回答中的步骤操作，点击回答下方的页面入口进入对应功能。
4. 切换页面或刷新当前标签页可继续对话；“清空对话”会移除当前记录。

结果确认：目标页面打开，原有对话仍保留。

常见问题：菜单、按钮或记录是否可见由账号权限决定。如果不知道 Excel 文件应放在哪里，请先说明它属于实验、数据中心、品管还是生产单。助手只指导操作，业务提交由你完成。

<!-- section: password -->
## 修改登录密码

入口：右上角账号菜单中的修改密码。

1. 进入修改密码页面。
2. 输入当前密码、新密码并确认新密码。
3. 按页面提示提交，使用新密码重新登录。

前置条件：已登录且知道当前密码。新密码至少 6 位。

结果确认：页面显示密码修改结果；修改密码后原有登录会话会失效。

常见问题：忘记当前密码时联系系统管理员，操作助手无法读取或重置密码。

<!-- section: customer-view -->
## 查找客户资料

入口：客户管理。

1. 输入公司名称、简称或负责人进行搜索。
2. 按行业、客户等级、合作状态、负责人筛选。
3. 在卡片或表格视图中点击客户名称，进入客户详情。

前置条件：具有客户查看权限。

结果确认：看到目标公司的资料。

常见问题：找不到资料时先取消筛选并核对名称；资料是否可见仍受账号的数据范围限制。

## 新建客户

入口：客户管理中的“新建客户”。

1. 点击“新建客户”。
2. 按表单填写公司资料和页面标记的必填项。
3. 核对后提交。

前置条件：具有新建客户权限。

结果确认：页面提示创建成功，列表中出现新客户。

待业务核对：客户等级的业务划分标准、负责人分配原则。

<!-- section: template-import -->
## 上传模板文件

入口：模板中心 → 模板上传。

1. 按页面选择模板分类及相关上传设置。
2. 选择要导入的模板文件。
3. 提交导入任务，在上传记录中跟踪处理状态。
4. 从任务入口进入模板工作台，核对原始文件、版式和识别字段。

前置条件：具有模板上传权限。

结果确认：文件形成可在模板工作台查看的模板草稿。

常见问题：上传完成不等于模板已经发布。用于业务导入的模板还需完成核对及发布。

<!-- section: template-view -->
## 查看模板与版本

入口：模板中心 → 模板查看。

1. 按分类和筛选条件查找模板。
2. 点击模板名称，或选择“查看模板”，进入模板工作台。
3. 查看文件内容及版本信息。

前置条件：具有模板查看权限。

结果确认：打开目标模板的具体版本。

常见问题：草稿和已发布版本用途不同；需要导入业务数据时，应选择已发布且用途正确的模板。

<!-- section: template-publish -->
## 核对并发布模板

入口：模板查看 → 选择模板 → 模板工作台。

1. 打开需要维护的模板草稿。
2. 核对模板内容、字段定义及业务用途，按工作台提示完成配置。
3. 保存草稿，并完成页面要求的审核和发布步骤。

前置条件：具有模板编辑和发布权限；审核操作另外受审核权限控制。

结果确认：模板状态显示为已发布，并可在对应业务导入页面选择。

常见问题：实验模板导入要求用途为实验数据（EXPERIMENT_DATA）、导入契约版本为 V9；生产单上传选择已发布的 Excel 生产单模板。具体字段含义需由业务人员核对。

## 查找项目及关联资料

入口：项目管理 → 项目列表。

1. 使用项目列表中的搜索和筛选找到目标项目。
2. 点击项目进入详情。
3. 在详情的相关标签页查看阶段、任务、文档及关联资料。
4. 从资料入口打开具体文档工作台。

前置条件：具有项目查看权限及目标项目的数据访问权限。

结果确认：打开目标项目和它关联的资料。

常见问题：操作助手提供项目列表入口，不会猜测具体项目或文档的记录编号。

## 新建项目

入口：项目列表中的“新建项目”。

1. 点击“新建项目”。
2. 填写项目名称，按需要选择所属客户、负责人、开始和结束日期等信息。
3. 补充团队成员和项目描述，检查页面提示。
4. 点击“创建”。

前置条件：具有项目创建权限。

结果确认：项目创建成功并可在项目列表查看。

常见问题：使用文件导入创建项目时，先核对 AI 识别结果，再确认创建。

待业务核对：项目优先级、阶段划分和验收规则。

## 在线新建实验记录

入口：电子实验记录本 → 在线新建。

1. 填写“文件名称”，选择权限设置。
2. 按需要关联项目、阶段或任务。
3. 选择“空白 Word”“空白 Excel”或“选择模板”；模板方式需选择已发布的实验模板。
4. 点击“创建并进入编辑”，在实验工作台填写记录。

前置条件：具有实验创建权限。

结果确认：实验记录创建成功并打开编辑工作台。

常见问题：已存在的实验文件应使用“文件导入”；在线新建用于创建新的记录。

<!-- section: experiment-import -->
## 导入实验文件

入口：电子实验记录本 → 文件导入。

1. 选择“实验分类”。
2. 选择可用于实验导入的已发布“实验数据模板”。
3. 按需要关联项目、阶段或任务。
4. 选择实验源文件，点击“开始上传”。
5. 在“导入历史”查看处理状态，从任务入口进入导入工作台，核对识别内容并按页面提示完成导入。

前置条件：具有实验创建权限；模板导入要求已发布的实验数据模板，用途为 EXPERIMENT_DATA，导入契约版本为 V9。

结果确认：任务完成核对和确认后，可以在“实验查看”中找到实验记录。

常见问题：单个文件最大 100M。页面支持 XLSX、DOCX、图片等文件；实际选择限制以当前上传区提示为准。没有可选模板时，需要具有模板维护权限的人员先配置并发布模板。上传成功只代表任务已提交。

## 使用 AI 研发问答

入口：AI研发助手 → AI问答。

1. 选择本次需要检索的知识库或数据分类。
2. 输入具体问题；需要时按页面设置开启互联网搜索。
3. 阅读回答，并打开引用来源核对证据。
4. 在同一会话中追问，保持问题主题明确。

前置条件：具有 AI 使用权限，模型服务已配置且来源资料可访问。

结果确认：回答附有支持其内容的来源资料。

常见问题：本功能回答研发资料问题；系统按钮和操作流程可以向右下角“操作助手”提问。

## 使用 AI 配方预测

入口：AI研发助手 → AI配方预测。

1. 进入配方预测页面。
2. 按页面填写目标、约束及必要的配方信息。
3. 检查输入后提交预测任务，查看结果和页面给出的限制说明。

前置条件：具有配方预测权限；模型及所需配置就绪。

结果确认：页面返回与本次输入对应的预测结果。

待业务核对：推荐配方的可行性、适用域和实际试验验证要求。预测结果不能作为已验证的实验结论。

## 使用性能预测

入口：AI研发助手 → 性能预测。

1. 打开性能预测页面。
2. 按页面选择预测目标和可用模型，填写必要输入。

前置条件：具有性能预测权限；相关模型已具备使用条件。

结果确认：得到与所选目标及输入对应的结果。

待业务核对：结果的验收阈值和实际实验复核流程。

## 查看模型中心

入口：AI研发助手 → 模型中心。

1. 在“模型列表”查看模型状态、训练记录数和验证指标。
2. 点击“查看模型”或该状态对应的查看按钮，核对模型详情与版本记录。
3. 点击“开始建模”或“建模工具”，从实验数据选择 X/Y 进行训练。

前置条件：具有模型查看或建模查看权限；训练与注册分别需要训练权限和模型发布权限。

结果确认：模型列表与建模工具集中在模型中心。

<!-- section: modeling-workbench -->
## 选择 X/Y 训练并注册模型

入口：AI研发助手 → 模型中心 → 建模工具。

1. 在“选择数据”勾选一张或多张实验数据表，原表预览默认勾选全部实验记录。点击表头勾选框可以全选或取消全选，也可逐条选择。
2. 点击“下一步：选择 X / Y”。多张表按名称、单位、数据类型和已知测试方法一致的字段合并使用。
3. 勾选输入 X，选择一个预测结果 Y。同一列不能同时作为 X 和 Y；至少需要 6 条完整记录，选中的 X 和 Y 必须有变化。
4. 点击“开始训练”，在“训练结果”查看算法比较和交叉验证指标。数值结果显示 MAE、RMSE 和 R²；类别结果显示准确率、宏平均 F1 等指标。
5. 点击“注册模型”，系统沿用本次训练的 X/Y、名称、单位、训练记录和模型文件。
6. 注册后点击“去预测”，填写所选 X 即可预测；点击“查看模型”可以查看来源数据、X/Y 和版本。

步骤按钮可点击切换；刷新后可恢复已保存的选择、训练结果和注册状态。“指标清单”用于查阅或导入名称、单位、测试方法参考，清单中的示例结果不参与训练。

前置条件：数据表中存在足够的完整记录。类别 Y 每个类别至少需要 2 条记录；类别 X 使用训练中已有的类别。

结果确认：注册成功后显示“已注册”和版本号。相同 X/Y 配置重新训练并注册会生成新版本；重复注册同一次训练不会生成副本。

常见问题：记录不足时返回原表增加选择，缺失值应补到对应实验记录中。已有模型保持原训练文件和记录；新增数据需要重新训练并注册。

## 查看模型版本与训练记录

入口：AI研发助手 → 模型中心 → 模型列表。

1. 搜索模型名称，按状态筛选；勾选“显示历史版本”查看旧版本。
2. 点击对应模型的查看按钮，查看算法、验证指标、版本记录。建模工具注册的模型还可查看原始来源表、X/Y 和参与训练的记录。
3. 在“训练任务”查看已有训练任务的状态和运行记录。

前置条件：具有模型查看权限；启用、暂停、回退需要模型发布权限，重试或取消已有训练任务需要训练权限。

结果确认：找到对应模型版本，状态变更会记录在版本记录中。

结果确认：找到目标库存变动。

常见问题：研发与生产库存应在对应的表中查询。冲销、新增和维护由各自权限控制。

<!-- section: inventory-create -->
## 登记库存变动

入口：研发库存表或生产库存表中的新增变动入口。

1. 选择业务所属的库存表，打开新增变动。
2. 填写日期、单号、产品名称、变动方向、业务原因、数量 KG 和经办人。
3. 核对数量及方向，按需要补充备注，点击“保存”。

前置条件：具有库存查看及新增库存业务权限。

结果确认：页面提示库存变动已保存，可以在流水中查看。

待业务核对：单号编制、盘点差异和不同业务原因的使用标准。
