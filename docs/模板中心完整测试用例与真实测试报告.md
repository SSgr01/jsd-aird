# JSD AIRD 模板中心完整测试用例

> 文档类型：功能测试用例与回归测试规范
> 测试范围：模板中心及其 AI 识别链路
> 测试数据前缀：`TEST-TPL-`

## 1. 测试目标与范围

验证模板中心从模板创建到发布使用的完整闭环：

`分类管理 → 空白创建/文件上传 → 文件解析 → 结构识别 → 字段识别 → 人工确认 → 字段映射 → 工作台编辑 → 保存 → 版本 → 发布 → 导出 → 数据中心模板查询兼容性`

主要范围：

- 模板查看、搜索、筛选、刷新和状态管理；
- 分类新建、编辑、简介、删除和模板迁移；
- 空白 Excel/Word 模板创建；
- Excel、Word 上传及导入记录；
- 规则识别、AI 结构识别、AI 字段识别和失败恢复；
- FORM_REGION、ROW_TABLE、COLUMN_TABLE、MATRIX_FIELD 等结构；
- 字段确认、一键确认、区域采用、字段映射和标准字段；
- Univer Sheets Excel 编辑器；
- Univer Docs Word 编辑器；
- 保存草稿、版本锁、结构哈希、发布、修订、导出；
- worker 异步任务、前端轮询和异常恢复；
- 模板 API、数据库记录、MinIO 文件和服务日志核验。

本规范不覆盖数据中心完整导入、RAG、OCR、ASR 的全流程验收，仅验证已发布模板仍能被数据中心模板查询接口读取。

AI 识别使用当前 `.env` 的真实配置，不使用模型桩。密钥、完整模型请求、完整模型响应不应写入执行记录。

## 2. 单条用例记录格式

| 字段 | 说明 |
|---|---|
| 用例编号 | 稳定编号，例如 `TPL-REC-001` |
| 优先级 | P0/P1/P2 |
| 前置条件 | 服务、用户、分类、模板状态 |
| 测试数据 | 文件、Sheet、区域和字段 |
| 操作入口 | 页面、按钮、菜单或编辑器原生工具 |
| 操作步骤 | 按实际鼠标、键盘、等待和刷新顺序记录 |
| 预期结果 | UI、API、数据库、MinIO、日志 |
| 实际结果 | 真实执行记录 |
| 状态 | 通过/失败/阻塞/未执行 |
| 证据 | 截图、网络记录、响应、SQL、日志 |
| 缺陷编号 | 失败时填写 |
| 请求/任务 ID | 关联服务端日志 |

证据目录：

- `screenshots/`：浏览器截图；
- `network/`：关键请求和轮询计数；
- `api/`：脱敏 API 响应；
- `logs/`：API、worker、前端日志；
- `sql/`：仅测试前缀相关的数据库结果；
- `fixtures/`：测试文件；
- `summary.json`：机器可读汇总。

## 15. 历史问题回归清单

以下问题必须在真实执行结果中单独给出通过/失败结论：

1. PostgreSQL `无法确定参数 $2 的数据类型`；
2. `WHEREa.organization_id = ?`；
3. `WHEREorganization_id = ?`；
4. `未设定参数值 15 的内容`；
5. `Connection reset by peer`；
6. `AsyncRequestNotUsableException: Response not usable after response errors`；
7. worker 启动后重新执行所有导入任务；
8. 前端完成后仍持续轮询；
9. 空白模板普通短文本字段不能自动发现；
10. 导入模板编辑不能自动发现字段；
11. 字段点击确认后仍显示待确认；
12. 简单长表不能一键确认；
13. 简单长表必须重复执行“采用区域并识别字段”；
14. 失效标准字段“日期”阻断或降级逻辑错误；
15. Word 自定义结构工具与 Univer 原生工具重复；
16. Word 表格插入后不显示或保存丢失；
17. Word segment ID 更新时缺少 headers/footers；
18. 页面显示模型原始响应、审计信息和英文内部状态；
19. 模板创建或列表仍显示用途、范围或 target 字段；
20. Excel 合并单元格预览显示为“列 1/列 2”而不是真实坐标。

## 16. 最终验收门槛

P0 必须全部通过：

- 分类可新增、编辑、清空简介和迁移删除；
- 空白 Excel/Word 模板可以创建；
- Excel/Word 上传、识别和失败恢复可用；
- 简单长表字段直接显示并可人工确认；
- 一键确认明确字段有效，单字段确认状态不回退；
- Excel 普通短文本自动发现有效，且不重复；
- FORM_REGION、ROW_TABLE、COLUMN_TABLE、MATRIX_FIELD 不被静默错误识别；
- 字段位置、数据路径、映射关系和属性可保存；
- 保存后重新打开不丢内容；
- Word 原生表格、列表、分页可见、可编辑、可保存和可导出；
- 发布校验能阻止不完整模板；
- 发布、修订、只读和导出符合版本规则；
- worker 不重复执行已完成任务；
- 前端不持续轮询；
- 不出现已知 SQL、连接、参数和 Word segment ID 错误；
- 页面不展示审计信息、模型原始响应、英文内部状态或模板用途字段。

外部 AI 服务不可用时，相关用例标记为“阻塞”或“失败”，不得伪造通过；规则识别、页面交互、保存和错误恢复仍继续执行。
