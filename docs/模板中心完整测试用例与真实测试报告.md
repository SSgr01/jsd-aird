## 1. 测试目标与范围

本次验证模板中心从模板创建到发布使用的完整闭环：

`分类管理 → 空白创建/文件上传 → 文件解析 → 结构识别 → 字段识别 → 人工确认 → 字段映射 → 工作台编辑 → 保存 → 版本 → 发布 → 导出 → 数据中心模板查询兼容性`

本次主范围：

- 模板查看、搜索、筛选、刷新和状态管理；
- 分类新建、编辑、简介、删除和模板迁移；
- 空白 Excel/Word 模板创建；
- Excel、Word 上传及导入记录；
- 规则识别、AI 结构识别、AI 字段识别和失败恢复；
- FORM_REGION、ROW_TABLE、COLUMN_TABLE、MATRIX_FIELD 等结构；
- 字段确认、一键确认、区域采用、字段映射和标准字段；
- Univer Sheets Excel 编辑器；
- Univer Docs Word 编辑器；
- 保存草稿、版本锁、结构哈希、发布、修订、导出；
- worker 异步任务、前端轮询和异常恢复；
- 模板 API、数据库记录、MinIO 文件和服务日志核验。

本次不做数据中心完整导入、RAG、OCR、ASR 的全流程验收，仅验证已发布模板仍能被数据中心模板查询接口读取。

AI 识别使用当前 `.env` 的真实配置，不使用模型桩。密钥、完整模型请求、完整模型响应不会写入本报告。

### 21.4 新发现缺陷

#### `DEF-TPL-011`：复杂真实模板的识别建议无法落库

复现文件：

- `光引发剂对比测试模板.xlsx`
- `阳离子单体_树脂性能及应用测试模板.xlsx`
- `应用测试报告模板.xlsx`

复现过程：

1. 通过 staging 上传真实 XLSX。
2. 创建模板导入任务。
3. worker 完成工作簿解析并调用真实识别模型。
4. 模型返回结构建议后，服务端在 `JdbcTemplateImportRepository.persistSuggestions` 写入 `tpl.recognition_suggestion`。
5. PostgreSQL 报错：

```text
org.postgresql.util.PSQLException:
错误: 对于可变字符类型来说，值太长了(64)
```

证据中的 SQL 位置：`JdbcTemplateImportRepository.java:704`，涉及表字段包括 `relation_id varchar(64)`、`block_id varchar(64)`。当前编译器为矩阵/复杂字段生成的关系标识可能由父关系、结构类型、字段编码和物理范围组成，长度可以超过 64；直接写入数据库会使整个识别事务失败。

影响：

- 真实复杂模板无法进入可确认字段页面；
- worker 会按重试策略重复执行模型调用；
- 识别建议已经生成但不能持久化，客户只能看到导入失败；
- 这直接影响复杂表、跨区域表和后续数据中心模板使用。

建议修复：

1. 新迁移将 `tpl.recognition_suggestion.relation_id`、`block_id`、必要时 `region_id` 改为 `varchar(256)` 或 `text`；不截断关系标识，避免同名冲突。
2. 对内部生成标识统一使用稳定短 ID，原始关系信息放入 `payload_jsonb`，并确保 `relationId`、`blockId`、`parentRelationId` 之间可追溯。
3. 在落库前增加长度校验和字段名日志，明确报告具体列名、长度和任务 ID，避免只返回“值太长了(64)”的泛化错误。
4. 增加真实长标签、合并区域、矩阵轴和多层表头测试，覆盖大于 64 字符的关系标识。

#### `DEF-TPL-012`：识别建议落库失败后 recognition run 未同步终止

上述 3 个失败任务的最终 API 状态均为 `FAILED`，并带有 `TEMPLATE_IMPORT_FAILED`，但同时返回：

```text
currentStage=DISCOVERING_STRUCTURE_REGIONS
recognitionRunStatus=RUNNING
```

影响：

- 前端可能继续轮询识别运行；
- 任务统计可能将已经失败的识别显示为进行中；
- worker 重启或重试时可能误判仍有活动运行。

建议修复：

1. 在 worker 任务达到最大重试次数时，同时调用 recognition repository 将对应 `recognition_run` 标记为 `FAILED`。
2. 保存失败阶段、异常类型、数据库列名、请求 ID 和原始错误摘要。
3. API 计算最终状态时，以导入任务终态和识别运行终态共同判断，不允许 `importJob=FAILED` 仍返回 `recognitionRun=RUNNING`。
4. 增加“识别建议落库失败”的终态测试，验证前端停止轮询。
