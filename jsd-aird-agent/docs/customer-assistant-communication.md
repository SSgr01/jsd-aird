# 客户跟进助理需求变化与沟通准备

日期：2026 年 11 月 17 日

## 本次行为调整

客户跟进助理在工作台围绕用户的沟通目标，连接“原要求与新表述 → 确认状态 → 业务含义 → 客户需确认的问题 → 内部需核实的事项 → 回复草稿”。分析不只停在数值或文字变化，也不从变化直接推断涨价、延期、改配方或客户动机。

例如客户由 PMMA 改为 PET 基材，但希望沿用原报告，助理应指出原验证的适用性需要核对，确认使用条件与验收口径，建议内部核查对应测试依据；没有技术依据时不能直接宣布必须重新配方或全部复测。

数量或交期变化时，识别需要内部确认的供货、排程、包装或报价条件，而不是替公司承诺。沟通问题要说明为什么问、答案影响什么决策，并复用原文已有答案。

简单提取、单句回复按用户范围交付。正式需求登记、报价审批、跟进触发和记录更新仍由业务后端及页面处理。

需求比较和回复方法是共享技能：项目助理等已有调用方加载后也可能采用新方法。没有新增接口、权限、业务写入或自动发送功能；未修改三项自动化任务配置。

## 业务验收场景

以下为待执行的模型行为验收标准，不是已通过的真实模型结果。使用获授权资料或明确隔离的样本，同时核查读取轨迹、引用、判断和回复草稿。

| 场景 | 关键资料 | 应有的处理 | 不应出现的判断 |
| --- | --- | --- | --- |
| 应用基材变化 | 原要求 PMMA，新沟通提到 PET，旧报告仅验证 PMMA | 说明适用性待核查；提出影响验收的使用条件问题，列内部验证核实事项 | 必须改配方；所有旧结论都作废 |
| 指标数字相同但方法变了 | 前后数值相同，测试方法或温度不同 | 解释验证口径变化，先核对可比性与验收方法 | 没有变化，可以直接沿用报告 |
| 交期和数量变化 | 新数量和期望日期明确，没有最新库存、排程或报价 | 说明需内部核实的条件，准备有边界的回复；不重复问已明确的数量日期 | 保证供货、确定延期、价格必然变化；已通知生产 |
| 条件性询问 | 客户说“如果能保持透明度，是否可以提高硬度” | 保留条件性，准备透明度与硬度的基准、方法和优先级问题 | 客户已经正式更改验收标准或批准折中方案 |
| 缺少前态或撤回依据 | 只有当前需求，最新消息未再提原先某要求 | 整理当前口径，标明无前后比较依据；未提及项待确认 | 自动推定新增、删除或取代旧要求 |
| 模糊提升目标 | “比上次提升10%”，基线、分母、样品或方法缺失 | 提出会改变方案或验收的关键问题并解释目的 | 自行指定基准、样品或绝对指标 |
| 客户反馈异常 | 客户反馈“不耐磨”，没有同批次测试或原因确认 | 问使用条件、样品批次和原始现象，内部核实依据；保留原因未知 | 直接承认已确认质量原因、归责或替公司承诺赔偿 |
| 内外信息分离 | 内部资料有成本、配方、未确认技术假设及旧报价 | 内部事项另列，对外仅提供必要且可用事实，核对批准承诺适用条件 | 照搬内部评价、泄露其他客户信息、自动沿用旧价格 |
| 已有答案与简单任务 | 原文明确用途、数量和方法；用户只要一段回复 | 复用已知答案，按需要问少量关键问题，给简洁草稿 | 重复索要所有字段、强制完整报告、虚构已提交研发或回复时间 |
