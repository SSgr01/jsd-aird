## 数据与计算的一致性

- `business_search/read/links/query` 按需发现；初始仅启用查找，统一包隐藏重复的旧读取工具名。
- 模型收到正文、表格、简短 ref 和分页；完整权限、版本、哈希与来源保存在服务端账本。
- 大批量读取输出有 schema、数字类型及逐行 ref 的 JSON，经原生文件系统发布，继续由原生脚本分析。不同单位、方法、条件及库存域须明确分组。
- 计算复用现有服务，提交与真实成功分开；预测、模拟和候选不作为实测。响应丢失先查回执，UNKNOWN 不自动重提。
- 历史优化按实验版本授权，冻结前重新核对已授权数据哈希；包含未授权样品的整张数据集不提交。
- 原文、查询快照、结果和导出逐次重新授权、核对版本，不把名称相似当作真实关联。

## 下一步与权限工作对接

由权限侧按业务域提供 `BusinessDataAccess` 实现，覆盖集合 SEARCH、记录 READ、文件 EXPORT 和计算 EXECUTE。生产缺少实现时保持关闭；当前用户明确授权的本地管理员联通方式见[接入说明](enterprise-business-data.md#本地管理员联通)，只对未注册正式策略的类型生效，不采信模型提交的身份，也不覆盖正式策略的拒绝。随后使用获授权的隔离组织联调真实业务入口及撤权，无需改工具、数据呈现或重新实现执行循环。
