# 可配置检索流水线与父块回取

问答和文献研究现在经过同一个 Java 编排器。Python 保留调度、任务预算、工具与证据导航，Node 运行唯一的 pi 循环。RCS 继续由研究能力独立调用。

## 入口与代码

| 入口／组件 | 职责 |
| --- | --- |
| `AssistantService → SharedRetrievalService.retrieveFixed` | 问答历史、文件／字段澄清及固定生成 |
| `AgentToolsController → SharedRetrievalService.documents/privateDocuments` | 兼容原研究工具，身份来自委托票据 |
| Java `ai/application/RetrievalPipeline` | 查询策略、召回编排、RRF、统一重排、排序分页、父块扩展 |
| Java `kb/application/KnowledgeService.recall` | 问答与当前知识库研究共用的原始 BM25、向量、元数据、兜底召回渠道 |
| Java `kb/application/ResearchKnowledgeService` | 授权／发布版本、历史原文词法召回、句柄回读、父块与精确跨度验证 |
| Java `ai/application/PrivateResearchSourceService` | 私有原文词法召回及同一账号、会话、版本的权威回读 |
| Java `shared/retrieval/RankFusion` | 共享 RRF；文件搜索兼容接口也使用该排序组件 |
| Python `evidence/navigation.py` | 任务内证据入口、排序快照、分页、重新授权与无进展检测 |

公共编排顺序：权限及版本范围 → 查询处理 → 各渠道原始召回 → 融合去重 → 重排 → 命中分页 → 父块回取 → 证据及上下文预算。

结构化记录和网页各自在可比较的召回组内排序；不把原始评分与 RRF 相加。固定问答仍只执行一次所需检索流程，研究仍按需调用工具。普通读原文、邻近上下文、父块续读、表格读取不重新执行检索。

## 服务端策略

配置位于 `application.yml` 的 `app.ai.retrieval`，由 `RetrievalPolicy` 在启动时验证。没有管理页面、数据库配置或模型可编辑的流水线参数。

- `profiles.qa`：沿用原查询理解开关和历史；BM25、向量、元数据及重排可独立关闭。
- `profiles.research`：默认关闭额外 LLM 改写；保留模型提交的查询。只有服务端显式开启时，控制层才预留一次辅助模型预算。缓存和排序快照回读不再计这次调用。
- RRF 默认 `k=60`；研究混合候选窗口先融合、重排，再按默认 12 条切页。精确词法查询跳过语义重排，私有／历史原文保留全范围词法结果。
- 重排未配置、失败、超时或返回不完整时保留可用候选；不按低语义评分清空精确命中。
- 指纹包含策略、配额及相关模型配置摘要。模型看不到内部 `ranking_snapshot`，不能用工具参数改写快照。

每次复用仍验证权限和来源权威性。自动库窗口另核对允许文献／发布版本的摘要；库窗口、身份、范围、版本或配置变化后重启该次搜索，保留原有合法证据及引用。恢复链继承轻量导航索引与策略指纹，不另存一套正文。

## 父块证据

最终 CHILD 命中确定后，仓储按 `parent_chunk_id` 一次批量读取，验证同组织、文档、文件版本、发布修订及 PARENT 角色。多个子块共用父块时只返回一次，`parent_links` 保存关联子证据 ID。

父块独立放在 `context_candidates`，角色为 `PARENT_CONTEXT`。它有自己的节点 ID、证据 ID、完整父块哈希、片段起止位置及片段哈希，不替换子块正文或 ID。

自动默认最多 3 个父块、各 2,000 个 Unicode 码点，总计不超过 6,000 及知识库上下文预算的三分之一。问答保留原 18,000 总预算和混合来源分配，包含头部开销；只给实际交给生成器的父块片段分配 K 别名。

问答压缩按检索排序分配预算，不再按页码或章节重组命中。每条命中保留独立来源标记和原有换行、表格行及段落边界，避免相邻记录串值或低排名长段挤掉更相关的方法段；预算末端截断仍明确标记。父块继续保持独立身份和完整片段，不在压缩阶段改写或截断父块正文。

片段优先覆盖能唯一定位的命中正文附近；定位不可靠则从父块开头读，并标注限制。片段逐字返回，不插省略号冒充权威正文。搜索、父块及相邻扩展均不增加全文覆盖。

`evidence_context` 新增 `relation=neighbors|parent`，默认不变。父块 `cursor` 为 Unicode 码点续读位置；`evidence_read` 仍通过现有 quote 句柄读取该证据片段。UI 区分父块片段、节点预览和片段内的精确引文。

缺失父块不丢弃有效子块；私有／历史节点缺少真实关系时返回不适用，不依据标题或当前索引猜测。权限拒绝继续返回权限错误。
