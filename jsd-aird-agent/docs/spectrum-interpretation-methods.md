# 图谱分析助理判读方法与条件核对

日期：2026 年 11 月 17 日

## 本次改动

图谱分析助理仍在工作台直接阅读用户所选原始页面。增强内容是按照实际检测原理选择判读方法，并针对所需结论核对条件，而不是只按分类标签描述峰形或一律询问全部仪器参数。

实际方法优先于分类提示，尤其不将 `HPLC_GPC` 自动当成某一种方法；粒径也须分清检测原理和统计口径。回答区分图片观察、报告数值、估读、计算和解释假设。条件不完整时仍可回答有依据的局部观察，但要说明哪些比较、定量或身份结论暂不成立。

角色和工作方法同步更新：

- `jsd-aird-api/src/main/resources/ai/expert-presets.json`：图谱助手简介、能力、任务示例、职责和核验规则。
- `jsd-aird-agent/enterprise-plugin/skills/spectrum-analysis/SKILL.md`：按类型的判读、条件和误判边界。

当前原生 Skill 运行时完整提供正文，参考文件资源不向模型暴露，因此各类型方法直接维护在同一个 Skill 中。没有修改图片选择、页面引用、业务接口、模型设置或正式质量放行流程。

## 各类型的增强重点

| 类型 | 判读方法与关键核对 | 需要避免的误判 |
| --- | --- | --- |
| IR / FTIR | 波数与轴方向、吸光度或透过率、ATR 或透射、峰位及重叠、制样和处理方式；反应程度另核对内标和积分方法 | 单峰直接定物质；不同采样模式直接比强度；图片峰高下降直接算转化率 |
| UV / UV-Vis | 区分吸光度、透过率、反射率；核对浓度、光程、空白、膜厚、散射和线性范围 | 吸光度更高就是浓度更高；不同膜厚直接比材料透明性 |
| HPLC / GC | 分清方法及检测器；核对分离、进样、稀释、响应、标准品和积分条件；GC 另核对温程及必要顶空条件 | 同保留时间直接鉴定；面积百分比直接等于质量纯度；截图精确积分 |
| GPC / SEC | 核对校准体系、检测器、溶剂、柱和积分范围，区分报告的 Mn、Mw 与分散系数 | 合并分类就确定方法；跨校准体系直接排名分子量；把 RI 信号当含量纯度 |
| 粒径 | 区分 DLS、激光衍射等原理，核对强度/体积/数量、平均定义、分散制样和重复性 | 混比不同口径 D50、Z-average；混淆 DLS PDI 与分子量分散系数；单图证明储存稳定 |
| 拉伸与力学 | 区分力位移、工程和真应力应变；核对截面积、标距、速率、应变测量、调湿和样本数 | 最大力直接当材料强度；横梁位移自动当应变；凭单条最佳曲线声称显著改善 |

校准、标准、阈值、参考谱和仪器参数必须来自实际资料，不自行采用“常见值”填补。不同仪器不直接判为不可比，仍应检查方法可比性依据。

## 待执行的业务验收

以下为行为验收标准，不是已经通过的真实图谱模型测试。验收应同时检查实际读图、条件来源、引用、推断及回答，不能仅凭回答提到了某类方法就认定通过。

| 场景 | 应出现的处理 | 不应出现的结论 |
| --- | --- | --- |
| 标签为 HPLC/GPC，仅有保留时间曲线 | 描述可见峰和报告明确字段；说明具体方法待确认 | 默认 GPC 并给 Mn/Mw，或默认 HPLC 直接判纯度 |
| IR 两图分别为 ATR 和透射，纵轴不同 | 解释观察方向与采样差异，收窄峰强比较 | 曲线更高所以含量更高、反应更完全 |
| IR 请求由截图计算转化率，缺内标与原始曲线 | 给可支持的定性特征及计算所缺依据 | 编造积分和精确转化率 |
| UV 吸光度不同但光程或浓度不同 | 核对比较基准；保留谱形观察，限制浓度判断 | 直接按吸光度排序浓度或性能 |
| HPLC 报告显示面积 98%，无响应校准 | 准确称为报告面积百分比，解释定量适用性待核查 | 认定质量纯度为 98% |
| GC 峰保留时间相近，方法或温程不同 | 核对方法和标准品证据，身份仍需确认 | 同保留时间即相同物质 |
| GPC 校准标准或检测器不同 | 明确校准及测量定义影响，限制跨样品排名 | 直接宣称某样品绝对分子量更大 |
| DLS 强度分布与体积分布并列 | 分清加权口径、转换条件及平均定义 | 直接比较峰高或 D50，认定粒径改善幅度 |
| 单张粒径图 PDI 很低，无重复和储存数据 | 描述报告数值及分布，指出稳定性证据不足 | 认定长期稳定或用未提供的阈值放行 |
| 力—位移图最大力不同，试样尺寸未知 | 描述最大力差异，说明缺几何和标距依据 | 换算精确强度、模量、断裂伸长率或材料韧性 |
| 单条力学最佳曲线 | 说明该试样结果及条件，统计结论留待重复数据 | 声称平均性能显著提升或批次稳定 |
| 只问一个可见峰，其他条件不全 | 就该峰回答可确认的观察，必要时说明估读与限制 | 强制补齐全部仪器参数才作任何回答 |
| 图例不清或报告值与曲线矛盾 | 不猜曲线身份；并列来源并指出待核对项 | 按颜色自配样品、静默挑一个数值当真 |
