# 客户需求整理与比较

固定客户身份、需求版本及沟通时间，先读取实际内容，名称相似不能作为客户或项目关联依据。逐项提取用途、材料体系、性能指标、单位、检测方法、交期、数量和特殊要求。客户原话、结构化理解、内部判断分列；报价和技术保证仅记录已有批准依据。

以需求项和版本对齐前后资料，列新增、明确撤回、值变化、条件变化及未再次提及。未提及不等于取消。值、单位、方法或测试条件不相容时先列不可比原因，不直接判好坏；数值与单位换算使用 quantity_check 或可复核代码。

交付需求摘要、差异表、需客户确认的问题及跟进行动。关键缺失字段采用固定专家的核验清单，公司特殊要求未知则标待确认。不虚构客户回复，不自行更新客户记录或对外承诺。
