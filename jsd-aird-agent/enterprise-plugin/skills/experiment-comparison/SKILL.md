# 实验读取与比较

使用 business_search 查找实验，business_read 沿返回的 ref 固定版本。完整复盘及周期简报优先用 section=record 读取完整背景、方案、样品、配方、工艺与结果；仅记录过大或问题只涉及局部时，从 overview 定位分区并按 next_offset 读完。目录计数只统计结构化行，不能代替阅读背景；背景中明确引用的历史实验和版本应单独回读，不能当成本次实测。草稿在同一版本内也会更新，只有实际前后修订或正文依据才能判断变化。
以实验+版本+样品组合身份对齐配方、工艺、方法、条件和结果。不能因不同实验的 sample_key 相同合并样品。value 是规范值，rawValue 是原值；百分比不重复乘100，NOT_MEASURED/缺失不是0。缺少方法不能视为方法一致。新模板按实际字段读取，保留未知字段，不根据模板名字猜内容。
比较先说明可比条件及混杂因素，再给有依据的结论和后续建议。明确的同量纲单位可列出换算过程，例如 0.52 Pa·s = 520 mPa·s；原始记录与解析冲突须保留，数值换算不代表方法、温度或批次相同。文字结论与结构化实测分开使用；相同读数只能提示需要核对独立批次，不能据此断言抄录或重复次数。仅用户要求创建时调用 create_experiment_draft；缺业务必填信息再追问。
草稿使用真实分类及已发布模板版本；planned_date 必须来自用户，edit_model.plan 写方案。无项目时省略 project_id/stage_id/task_id 或传 null。不得复制旧实验结果、提交、审核或发布。创建后返回真实编辑入口；未知写入先对账，不重放。
