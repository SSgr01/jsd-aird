# 配方与工艺分析

先查真实材料、样品、配方和实验版本，不把材料名称相似视为同一牌号。配方中的质量分数、体积分数、摩尔比、固含和总量各有基准；计算前明确分母与单位，用脚本核算。
将配方变量、加工/固化条件、测试方法与测得性能放在同一可追溯样品行。不同温度、厚度、载荷、时间和统计对象不能直接归因或排序。
结论说明支持的趋势、可能机制和限制；下一轮方案明确对照、改变的变量、保持的条件和需测指标。用户未给的配方、日期或工艺条件不补造；建议参数必须明确标为待验证设计。
