# 配方与工艺分析

围绕用户提出的性能问题分析；单个材料作用、配方核算或局部问题直接回答，不强制完整诊断。诊断时先明确异常现象、比较基准和目标指标：相对哪一版本或对照变差、差多少、在哪些条件下出现。目标、验收限值与用户希望改进的方向分开；缺少会改变判断的信息时定向询问，其余保留有依据的局部结论。

## 核对差异及其条件

先查真实材料牌号、原料批次、实验版本和样品身份，不把名称相似视为同一材料。用 experiment-comparison 沿实际记录对齐配方、制备、加工/固化、调理或老化、测试方法与结果；优先核对会改变本题判断的条件，例如涂层基材和膜厚、实际固化条件、载荷与测试时间。未记录不等于一致，历史结果、未测值与本次实测分开。

配方中的质量分数、体积分数、摩尔比、固含和总量各有基准；计算前明确分母、单位和原料有效含量，用脚本核算。调整一项可能同时改变总量、固含、当量比或其他组分占比，不能假称只改变一个因素。

先判断异常是否有实测支持、比较是否成立。条件不齐或存在冲突时指出哪些趋势仍可描述、哪些归因暂不成立；不能因不能直接比较就否定原记录，也不把文字评价替代实测。

## 从现象提出待验证原因

按问题考虑材料/配方、制备/固化、界面/分散、储存/使用及测试本身的可能影响，只保留与证据有关的解释，不逐类凑数。已有明确证据支持单一解释时不强凑第二个；资料不足时可以保留待查方向，不包装成诊断结论。

对关键候选原因说明：哪些已读记录或原文支持、哪些证据相反或尚缺、还存在哪些混杂因素、什么观测能使该解释减弱。没有反证不等于已证明；一组数据同时变化多个条件，不能把性能差异单独归给某一组分。文献机理只能支持适用条件下的候选解释，不能代替当前样品验证；不编造出处、原因概率或确定性排名。

诊断交付连接“观察差异—候选解释及证据—优先核实项”。按现有证据、目标影响和验证成本解释先后顺序，再用 research-design 将关键假设转成可判别实验。暂不能区分原因时优先补条件或设计区分实验，不直接断言应改配方；建议参数标为待验证设计，不补造用户未给的配方、日期或工艺事实。
