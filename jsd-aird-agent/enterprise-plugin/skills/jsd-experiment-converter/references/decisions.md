# 转换决策（统一后的业务规则）

这些规则保留原有业务约束，替代旧文档里互相冲突的重复描述。用户当前明确要求优先。

## 分类和交付

目录分类优先；按实验内容区分合成记录和测试记录，不按文件后缀推断实验类型。每源文件一份 XLSX，每张有意义源表一张标准表，不因超容量拆表。表名第一张为 `测试实验/合成实验`，后续保留前缀加区分后缀。

分组实验和有明确来源的单组检测记录可以进入模板；单组无配方、无平行样时使用 `single_group_test`，缺失配方和条件保持空白，不补造编号。光谱汇总、单物料物性汇总或配方横向对比等非实验记录，按内容判断、列明并跳过。已有明确分类可复用，不必每次重问全部清单。

## 字段判断表

| 源与模板关系 | 处理 |
|---|---|
| 含义和条件相同，名称有明确同义词（粘度/黏度） | 对应字段，保留原值；不能仅用子串匹配 |
| 同一测量的不同时间点（如初始与放置12小时后的翘曲） | 主要/初始值进原字段；其余原值进未落位清单，提议时间轴；不自动新增时间点行 |
| 原始平行板/重复测量 | 每个原值、板号、条件都必须有出处；已有对应行可用。无对应字段且不满足下面新增项条件的，进未落位清单。均值不能替代原值 |
| 不同测试体系/暴露的项目（如自由基体系水接触角与水接触角） | 不得合并；只有满足新增项条件才另加行，否则进未落位清单 |
| 模板按负重区分硬度，源只说明膜厚/基材 | 不能猜负重，不硬填某一硬度行；进未落位清单并提出模板维度建议 |
| 有原值但完全无字段，例如逐组日期、长篇观察 | 外部未落位清单；不塞入备注 |
| 单纯空白、未测、数值0、明确不使用 `/` | 保持区分，不补值、不将空白当0；配方合计时空白和 `/` 贡献0 |

**新增测试项行同时满足：** 源本身是客户填写的标准模板稿；客户在其中追加了该项；它是现有维度中的新项目，不是全新时间/负重/膜厚轴。按区块骨架而非标签命中率判断模板稿；还要读具体标签确认，`is_template_copy.py` 只是线索。保留新增标签原文，位置跟随源的前驱项，区块 A 列纵向合并同步扩展。`execute_plan.py` 根据明确的 `client_template_additions` 声明执行配方合计后的安全插行，语义资格仍需读源确认，不能以旧执行器缺能力为由把合格项目全部外置。

配方物料超行数、分组超列数则必须直接扩容，两轴可同时增加，不受新增测试项条件限制。所有下游行号、合并、公式、验证与打印范围一起修正。源中的主标签只写一次、子项在旁列时，按标签所在块向下继承，不漏 PET/PMMA 等子项。

## 数值与来源

不推断单位，不混用 UV 与烘烤条件。不拿示例或相邻组回填。估计值写纯数字，估计属性只在外部报告说明；不加估计列。原报告均值与原始板值分别保留，源没有均值不自行声称存在。

备注仅取实验室原文。源无备注就留空；文档保密页脚、来源说明、转换限制、未落位数据都不是备注。未落位清单至少含源表/单元格、原值、原因、建议字段，放在 `转换结果/` 之外。

## 模板与合计

每张输出必须从空模板开始。可在同一个工作簿里保留一张始终未填写的 pristine 模板，复制它并显式恢复验证、视图及打印设置，最后删除 pristine；禁止从已填的输出复制下一张。这避免了旧 XML 合并工具不合并样式表/共享字符串的风险。

配方是稀疏矩阵，不能要求每个命名物料在每组都有用量。数字、空白和 `/` 配方使用生成的 `IF(COUNTA(range)=0,"",SUM(range))` 合计；非数字单位文本先明确转换或报阻塞。原模板要求物料/用量一一成对的复杂公式不适用稀疏矩阵，扩容时不能照搬枚举行号公式。

执行器仅为自己生成且已检查过数值类型的 SUM 合计构建缓存，用 Decimal 与 fsum 两条计算路径核对，并与源合计（若有）比较。它不是 Excel/LibreOffice 通用计算引擎。其他公式不得伪造缓存；需要当前环境的重算引擎，不能为此另开发一个求值器。

## 完成与阻塞

逐格核对、组/物料计数、合计、模板标签、验证和输出范围通过后，才标为校验通过。有明确未落位项时一并报告；不说明未落位项的“全量完成”不成立。计划执行正确不等于语义映射正确。

具体文件出错记录具体文件，其他文件继续。缺解释器、陌生模板、无缓存源公式、无法解释的转换差异都保留为可恢复的阻塞；不要用无期限重试掩盖它。文件后缀不同、可处理的旧格式、已确定的分类都不是重新征求确认的理由。
