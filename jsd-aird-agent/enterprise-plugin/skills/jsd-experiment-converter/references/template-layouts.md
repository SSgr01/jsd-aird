# 当前模板布局提示

实际工作区模板优先；这些坐标只是2026年10月样本的提示。按模板SHA256复用已确认布局，指纹变化后才重新检查；不要每次重新研究两份模板与两份模拟示例。

| 项目 | test.xlsx / 测试实验 | synthesis.xlsx / 合成实验 |
|---|---|---|
| 大小 | 138行×8列 | 54行×8列 |
| 分组 | C:H，初始6组 | C:H，初始6组 |
| 组编号 | 第7行及第51行同步 | 第9行 |
| 物料名 / 用量 | B52:B59 / C52:H59 | B10:B23 / C10:H23 |
| 合计 | 第60行 用量合计（g） | 第24行 质量合计（g） |
| 配方验证 | C52:H59 custom | C10:H23 custom |
| 固化方式下拉 | C10:H10 list | 无 |
| 备注 | B138合并值区 | B52合并值区 |

测试模板的树脂属性从第19行开始，**第24行已经有黏度字段**；不要沿用旧运行报告里“模板缺黏度”的结论。测试基材在第8行分组值区；合成模板的 A8/B8 是实验内容标签，值在 C8:H8。标题在 B1:H1，不能覆盖 A1。

两份模板第二行还有横向字段：C2=日期、E2=环境温度、G2=相对湿度，对应可写值在 D2/F2/H2。不要只检查A/B列就声称这些字段不存在。逐组日期与单个全表日期仍不能混为一谈。

`template_ops.layout()` 从标签、合计和配方验证区推导当前模板布局，不用固定52/60行作为扩容算法。配方加行位置在原合计之前；所有原合计及下游行向下移。组列超过H时，复制空模板组列样式，延长合并标题、配方验证、固化下拉和打印宽度。

使用未填写的模板底稿生成每张输出，显式恢复验证、冻结、视图及打印属性；别复制已填数据表。扩容后重写配方合计覆盖整个新区域。

新增测试项行及多时间点的取舍只由 decisions.md 决定，不能从“可扩容”推导为“一律扩行”。模拟示例（若有）只用于不清楚的字段类型，不加载其中的SIM值作为真实数据。
