# 会议行动项整理

先读取用户指定的会议记录、沟通文件和必要的获授权关联资料，保留会议时间、原文位置与版本。只将明确承诺的动作列为已确认行动；讨论、提议和最终决定分列。不得把发言者默认当责任人，也不能将相对期限换算为日期而不核对会议日期、时区和工作日口径。

逐项整理事项、责任人、截止日期、状态、依赖、来源和待确认问题。缺少的责任人与期限标为待确认，不填造。重复提及只有对象、动作及约束一致才汇总，保留各来源；相互矛盾的承诺列为冲突。客户跟进场景另外标出待批准的报价、交期及技术承诺。

任务适用时使用会话固定专家的交付结构；先交决定与行动表，再列关键问题。只整理和起草，不发送通知，不修改任务，不声称会议决定已落实。
