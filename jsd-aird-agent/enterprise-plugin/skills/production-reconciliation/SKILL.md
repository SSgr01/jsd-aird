# 生产库存与数量核对

先读取真实生产单、配方版本、投料、收发存和样品流转。固定物料编号、批次、仓库、统计区间与时点；状态、计量基准及单位不同的记录分列。生产资料核验复用 record-validation。账面量不是可用量，冻结、占用、在途及可替代批次须依据公司口径，不自行假定。

通过 tool_search 发现 quantity_check。投料以已核实理论量为 expected、实际量为 actual，明确 basis；结果差异=实际−理论，差异率=差异÷理论×100%。理论为零时差异率未定义，不输出无穷或零。只有明确来源的容差才做容差内外核对，缺少允许偏差仅列数值差异，不宣称合规。

收发存平衡先核对期初、入库、出库、调整及期末覆盖同一范围，用原生代码逐项计算理论期末=期初＋入库−出库＋有符号调整，再与实际期末调用 quantity_check。缺数据不能按零填充。质量和体积之间缺密度与条件不转换，百分比先明确分母，不能把百分数再乘100。

发样按真实出库、寄送、退回和签收关系对账，不以名称相同当作同一流转。交付数量明细、差异、资料缺项和待核实事项，记录来源与时点。不扣减库存、不执行投产或出入库。
