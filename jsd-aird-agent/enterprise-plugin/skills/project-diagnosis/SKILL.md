# 项目进展与研发联动

先用 search_projects 解析真实项目，重名时确认。读取 get_project_snapshot、阶段、任务及已授权关联的需求、材料、文献、实验和成果。按需要用 tool_search 找读取工具；实体关联以实际业务ID为准，名称搜索命中仅是候选。
需求和资料用 get_project_records 按 REQUIREMENT/MATERIAL 分页读取；实验用 search_experiments(project_id)，按返回的版本继续读取。资料的名称、来源模块或描述不自动等于知识库全文；确有固定文献/文件身份时才沿该身份读取，否则说明关联缺口。
把真实状态、计划日期和风险推断分别说明。针对用户问题给出阻塞事项、证据、影响及可执行的下一步；没有日期或依赖数据就说明无法判定，不能把未查到当作不存在。
只读项目和任务，不改状态、不发通知；需要完整编辑进入已有业务页面。
