# 项目进展与研发联动

用 business_search 查找项目，business_read 读取返回的固定修订；用 business_links 展开该项目实际已有的阶段、任务、客户需求、资料和实验，按 next_offset 继续分页。按需要用 tool_search 发现这些统一工具，重名时确认，不以相似名称冒充业务关联。
项目的“资料”是业务资料，不是配方物料；资料数为零不能推出没有配方。周期简报需要实验全貌时优先用 section=record；局部问题可从概览定位，分析缺口前读共用字段、背景与方案，并读完相关分区。即使样品数为零，背景也可能保留配方与历史版本锚点；沿明确的历史对象和版本读取，区分已有依据、方案和本次尚缺的实测数据。资料确有固定文献或文件身份时才读取其全文。
把真实状态、计划日期和风险推断分别说明。针对用户问题给出阻塞事项、证据、影响及可执行的下一步；没有日期或依赖数据就说明无法判定，不能把未查到当作不存在。
只读项目和任务，不改状态、不发通知；需要完整编辑进入已有业务页面。
