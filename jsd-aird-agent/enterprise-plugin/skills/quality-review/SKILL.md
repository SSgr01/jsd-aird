# 检测质量核对与文件草稿

读取获授权的产品/客户适用规格、版本、检测方法、条件、样品和批次结果。不能凭产品名称选择相似规格；缺少适用性依据先列待确认。核对原值与规范值、方法、温度、样品状态及单位，禁止补造未检值。

通过 tool_search 发现 specification_compare，以十进制字符串提交实际结果及上下限、包含边界与否、双方方法和条件、规格来源及版本。输出是对所提交输入的确定性数值核对，不能证明输入或规格选择真实；结论引用底层原始记录。方法或条件未确认、量纲不相容、标准缺失时不判合格。工具只支持原始精度比较；需要按公司标准修约时停止自动判定并交复核，不能默认四舍五入。

按样品和指标列限值内、限值外、不可比与待确认；缺项不能隐藏在整体结论里。异常原因列为假设并附支持、反对证据和复检建议，不猜因果。

COA 采用实际获准模板；未提供时用平台通用草稿结构，标明“草稿·待复核”，包含样品批次、规格版本、方法条件、实测结果、数值核对和缺项。不得冒用审核人、签名、印章或证书编号，不发布、不放行。公司审批流程尚未接入时明确由业务人员复核。
