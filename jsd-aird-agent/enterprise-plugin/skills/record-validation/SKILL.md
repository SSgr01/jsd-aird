# 记录整理与核验

读取任务指定的真实模板、字段字典及原始记录。固定专家的 checks 为通用默认值，实际业务模板有额外必填字段时一并核验。将源字段映射到有明确定义的业务字段，保留原值、行号、记录版本和来源；未知字段不删除，空白、未检测与零分开。

通过 tool_search 发现 record_validate，提交已读取的平面字段记录。服务端自动合并会话固定专家的必填字段；额外规则只约束本次核验，不保存为个人配置。检查输出中的缺项、缺少组合标识、精确重复与同标识冲突。不用模糊名称自动合并，不静默采用较新值覆盖冲突。大表在原生沙箱按同样规则分批核验，不能只看首批后声称覆盖全部。

实验按实验＋记录版本＋样品识别，另读取真实项目/配方/原料批次关联；工具计算只能检查提供的数据，不能证明业务关联或来源真实。记录关系只能依据关联工具或明确业务字段核实。单位换算发现 quantity_check；未知单位或跨量纲不自动换算。编号规则未提供时只提示缺口，不自行生成公司编号。

交付整理结果、缺项清单、关联异常、重复冲突及转换规则，保留所有原始值与来源。核验通过只代表已检查字段，不代表实验有效、库存可用或质量放行；缺失实测值绝不以预测补齐。只保存用户要求且平台支持的新文件或草稿。
