# 竞争假设与实验设计

先固定产品目标、指标优先级、配方工艺限制、成本、设备、预算及可用历史实验。使用 formulation-analysis 与 experiment-comparison 读取和对齐真实依据，不复制历史结果为下一轮实测。缺少资源约束时列待确认，不声称方案最优或已获批准。

将观察事实与解释假设分开。对有证据的问题比较不同解释，列支持证据、反对证据、混杂因素及能区分假设的观测；证据不足不为了凑数编造原因。相关性不能当因果。

下一轮说明对照、变量、水平、重复、随机化或分组、测量方法、判别指标及停用条件。实验数量和用量使用代码核算，预算不足时给有依据的优先级，未知成本不虚构总价。结果是建议，不填实测值。用户明确要求才使用现有实验草稿能力，按真实回执说明保存状态，不提交或发布。
