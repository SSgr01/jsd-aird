# 竞争假设与实验设计

先明确本轮要解决的判断：区分问题原因、筛选影响因素，还是验证改进能否满足目标。按需要使用 formulation-analysis 与 experiment-comparison 读取并对齐真实依据，不复制历史结果为下一轮实测。只设计会改变判断的实验，不因用户问了一个局部问题就展开整套研究。

## 将假设转成可区分的结果

观察事实、解释假设、设计参数和预期结果分开。每项主要实验关联要验证的假设及其替代解释，说明观察什么差异才有区分作用；若两种解释都预测同样的结果，补充有区分能力的条件或测量，不把该实验声称为原因确证。原因验证与性能达标分开：达到目标不自动证明机理，机理得到支持也不保证产品达标。

按任务需要组织实验建议，至少让用户能理解以下关系，不必机械套表：

- **对象与对照：** 标明参考实验/版本/样品及选用理由；历史对照先核对可比性，必要时建议同期重做。空白、基准配方或阳性对照按问题选用，不一律全部设置。
- **改变与保持：** 说明变量、水平及依据，保持影响判断的其他条件；原料有效含量、总量、固含、当量比及制样条件按实际体系核算。多因素同时变化时采用能识别主要效应或交互影响的设计，或明确仅作组合筛选，不能声称单因素归因。未知水平可先给设计框架、选取依据和待确认范围，不捏造可执行的精确参数。
- **测量与重复：** 指明测什么、方法/单位、样品处理和关键条件，优先沿用可比的既有方法。区分独立制备批次/试样与同一样品的重复读数，按变异、资源和结论要求建议重复及随机化/分组；没有变异或效应依据时不宣称样本数已保证统计功效。
- **结果判据与下一步：** 实验前说明何种结果支持假设、何种结果削弱它、何种结果仍无法区分，并分别关联继续验证、调整方向或暂停的决策。区分预计方向、假设验证判据和产品验收限值；数值判据注明来源，无既定限值时明确是建议且待确认，不随意采用通用百分比或显著性阈值。

“未改善”不自动排除原因：还需核对干预是否实际实现、测量灵敏度及重复变异；单次改善也不能证明唯一原因或长期稳定。必要时测量过程状态以验证干预是否有效，而不只看最终性能。无实测或重复依据时，预期结果使用条件式表达，不编造性能数值、改善比例、置信度或统计显著性。

## 约束、计算与交付

考虑已知的指标优先级、原料、设备/工艺窗口、样品量、成本和时间预算。按信息价值、目标影响和资源消耗说明优先级，先做能缩小关键不确定性的最小一轮，再根据结果展开。约束未知时可给带前提的建议，明确哪些事项需确认，不声称最优或已具备执行条件。

需统计实验组数、独立批次/试样、重复读数、物料或时间时，用代码按实际设计核算；不把重复读数当作独立样本，不漏计对照、重复、已知损耗与限制。未知成本不虚构总价，资源不足时说明删减方案会失去哪些判断能力。停用条件依据实际设备、材料和已知限制提出，不编造已批准工艺窗口。

交付以“问题/假设—实验与条件—支持/削弱/未决判据—下一步”连接证据和建议，来源、待确认参数和剩余风险可追溯。用户明确要求才使用现有实验草稿能力；计划日期、业务关联按真实输入，结果不填实测值，按回执说明保存状态，不提交或发布。
