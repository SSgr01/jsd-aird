# 图谱分析

围绕用户问题使用本轮选择的图谱和原始页码；连续追问可沿用原生会话中已读图片。具体峰、曲线或数值问题先直接回答能确认的部分，不机械地索要全部仪器参数或套用完整报告。定量、跨样品排名、身份鉴别等结论才核对支撑该判断的关键条件。

## 取得原图与确认技术类型

先核对来源、样品、批次、测试条件、图例与坐标轴。图谱目录、文件路径、元数据和过去的助手回答都不等于已经看到图片。

选择器会将所选页面作为原生图片附件发送，并附带固定来源引用。缺少图片、需要放大或补读时，通过 tool_search 找到 business_read，传入返回的真实 ref、section=page、page=原始页码、include_file=true，再调用 read_image(file_path=business_file.path)。仅下载成功不能称为已阅读。每张图谱原始页码从1开始，不用附件排列序号代替。权限不足、文件版本变化或模型不支持图片时说明阻塞，不猜图像内容。

技术类型依据实际坐标、报告字段、方法和检测原理判断，分类标签仅是线索。`HPLC_GPC` 不能自动当作 HPLC 或 GPC；同一粒径分类也不代表都是 DLS。方法尚不能确认时保留已见特征，说明歧义，不套用错误指标。其他类型按实际方法处理，不硬归入下列类别。

## 按结论需要核对条件

本轮业务图谱上下文中的 `testMethodSnapshot` 是随图谱保存的当次登记条件，`testConditions` 是其可读摘要，`conditionWarnings` 只提示可能影响比较的缺项。优先结合这些条件与原始页核对；预设带入不证明仪器实际执行，原报告与登记值冲突时并列来源，不静默覆盖。不得用预设的最新版本替换旧图谱的条件，也不从“未填”推断为相同或常用值。多方法文件只把明确对应页／样品的条件用于该曲线。

比较时明确指出与当前问题相关的差异：ATR 与透射不直接比较峰强；紫外浓度或光程不同不直接按吸光度排名；GPC 标样／校准不明不直接排名分子量；粒径介质、温度、强度／体积／数量口径不同须限制比较；GC 温程未完整记录时不由起终温和总时长推算；拉伸缺实测宽厚时不把最大力换算为强度。继续回答已有证据支持的局部观察，不机械索要所有条件。

登记条件、报告明示值和用户补充值分别标明来源，不把用户给出的最大力等结果写成条件快照中的字段。缺厚度时只给计算公式及缺项，不自行选取假设厚度举出强度数值。未取得标准的相应版本原文时，不凭记忆给出试样标准尺寸或断言其合规性；名义尺寸始终不能替代实测尺寸。仅凭曲线相似不能确认发色团或化学结构相近；未经拟合的粒径曲线不直接定名为对数正态分布。

先核对曲线对应的样品、原始页、轴名称和单位、线性或对数刻度、范围和图例。比较强度、面积或斜率前，再核对纵向平移、归一化、基线扣除、平滑、稀释及仪器响应等相关处理；图像显示范围不同不能直接用视觉高度排名。多曲线图例不清时不按颜色猜样品身份。

方法和条件有依据相容、存在可解释差异，或尚未确认，分别收窄为可比较的量、定性观察或暂不能判断的结论。未写条件不是条件相同；不同仪器也不自动等于不可比，应查方法可比性依据。仅缺少不影响局部观察的条件时继续回答，不把所有未知项都变成阻塞。

## 红外 IR 与 FTIR

- **先读坐标和模式。** 确认波数及单位、吸光度或透过率、波数轴方向，以及 ATR、透射或其他已说明模式。透过率谷与吸光度峰的方向不同；纵向平移或归一化后不直接比较绝对强度。
- **再读有证据的特征。** 按可见或报告明确峰位、宽度、肩峰和重叠区域描述，比较新增、减弱、位移和谱形差异。官能团指认是结合材料背景、多个特征和参考谱的候选解释，不凭单一峰认定物质身份；接近分辨能力的位移不夸大解释。
- **比较前核对。** 采样模式、样品状态、制样或厚度、ATR 接触与校正、分辨率、背景和归一化依据按问题核对。模式或接触不同可能影响相对峰强；水、二氧化碳或基线异常只能列待验证解释，不能直接扣除或认定污染。
- **反应程度需额外依据。** 比较转化率要有可追溯的反应前后样品、适用峰与稳定内标、同口径基线和积分方法。图片峰高下降或峰看似消失不能直接给转化率、反应完全或纯度结论。

## 紫外可见 UV 与 UV-Vis

- **确认所测量。** 区分吸光度、透过率与反射率；识别波长、基线、峰位、肩峰和饱和或截顶现象。溶液吸收与薄膜透过率不能直接混为同一个性能指标。
- **核对比较条件。** 溶剂和空白、浓度与稀释倍数、光程、样品状态、薄膜厚度、波长范围及仪器带宽按结论需要核对；有散射或浑浊时不能把全部变化直接归为吸收。归一化曲线可比较一定的谱形，不能恢复原始吸光强度。
- **限定推断。** 峰位变化可以描述，但原因需结合材料与条件列为解释；不能仅凭吸光度高判断浓度更高或材料更好。用校准曲线或 Beer–Lambert 关系推浓度时须有适用线性范围、光程、浓度基准和校准或吸光系数依据；没有这些依据就保留定性观察。未知膜厚下不直接比较材料本征透明性。

## 液相 HPLC 与气相 GC

- **识别方法和检测器。** 先确认属于 HPLC、GC 或其他分离方法。HPLC 按需要核对色谱柱、流动相与梯度、流速、柱温、检测器及波长、进样量与样品浓度；GC 核对柱、载气流量、温程、进样与分流、检测器和样品前处理，顶空样品还需顶空条件。缺失条件不自行设常用值。
- **判读峰形和分离。** 描述保留时间、可见峰、拖尾、肩峰、基线和潜在重叠；报告峰面积、面积百分比与峰高分别说明。不能把每个小峰直接命名为杂质，也不把未见峰说成绝对不存在；共洗脱、检测响应和检出范围会限制观察。
- **身份和含量分别论证。** 同保留时间只是线索，身份需要适用标准品或其他确认依据。面积百分比不是未经校准的质量纯度或浓度；面积归一化法的适用性、响应因子、未检组分及积分规则须有依据。样品稀释或进样量不同不直接比较峰面积。
- **数值计算有入口限制。** 只引用报告已给出的积分值；从原始数值曲线重新计算时须有时间/信号数据、适用基线、峰边界和方法，用可复核代码计算并保留输入。仅凭截图不自行积分，不从像素估出精确分离度、理论塔板数或纯度。
- **异常不等于原因。** 保留时间漂移、峰展宽或响应下降可提出方法、制样、系统或样品方面的候选原因与区分建议，不直接认定降解、污染或某组分含量变化。

## 凝胶渗透 GPC 与体积排阻 SEC

- **确认检测语义。** 结合方法、校准和报告确认是 GPC/SEC，而不是仅凭液相分类或保留时间轴下结论。读取 Mn、Mw、分散系数 Đ、分子量单位及报告的校准方式，区分相对标定结果与有依据的其他测量方式。
- **核对方法条件。** 样品溶解与过滤、溶剂/流动相、柱及分离范围、温度、流速、检测器、校准标样和曲线、积分范围按判断需要核对。RI、UV、多角度光散射或黏度检测的解释条件不同，不能仅凭仪器名称宣称得到绝对分子量。
- **解释曲线和参数。** 在适用的 SEC 分离条件及同口径方法下，洗脱变化可提示流体力学体积变化；不能跨校准体系直接排名分子量，也不从保留时间自行换算 Mn/Mw。报告给出 Mw/Mn 时可用代码核对，明确这不验证校准和积分正确性。
- **避免机理越界。** 宽峰、多峰或高分子量尾部可作为分布差异，聚集、支化、非体积排阻作用等只列候选解释；不直接等同于发生聚合或降解。只有溶解并进入检测范围的部分被测得，不能用可溶组分曲线直接代表凝胶含量或全部样品。

## 粒径与粒度分布

- **先辨原理和口径。** 区分 DLS、激光衍射或其他明确方法。确认横轴单位和线性/对数刻度、纵轴是强度、体积、数量分布还是累积比例；D10/D50/D90 核对报告的分布基准和累积定义。不同基准的 D50 不直接对比。
- **按方法读指标。** DLS 的 Z-average、累积法 PDI 与分布峰值不是同一量；不能把 PDI 当成 GPC 的 Mw/Mn，也不能从激光衍射曲线猜 DLS 指标。强度分布转换为体积或数量分布依赖模型及光学参数，不能只改标签。
- **核对条件。** 分散介质、浓度、稀释、分散或超声方式、温度、黏度与光学参数，以及对应方法的角度/分析模型和重复测量按需要核对。处理不同、浓度效应或灰尘可能影响结果，不直接把大粒径峰认定为团聚或污染。
- **限制结论。** 描述多峰、尾部和报告指标及重复性；单张分布图不能证明储存稳定性或批次重复性，单个均值也不能代表分布完全一致。没有适用规格不套用通用 PDI 阈值判合格。

## 拉伸与其他力学曲线

- **先区分坐标。** 力—位移、工程应力—应变、真应力—真应变各自解释，不能混称。最大力不等于强度，位移不等于应变；按同一力比较材料强弱前需核对截面积。
- **核对试样与方法。** 测试模式和标准版本、试样形状与截面积、膜厚、标距、取样方向、制备固化与调湿、温湿度、速率、应变测量方式、重复次数和有效样本按问题核对。横梁位移不自动等于引伸计测得的标距变形。
- **读曲线和定义。** 区分屈服、最大应力、断裂应力、断裂伸长率及弹性模量；没有清晰屈服特征不强行找屈服点。模量需要应变定义、适用拟合区间与零点/顺应性处理；曲线初段视觉斜率不是可直接报告的精确模量。
- **计算与比较。** 原始力、截面积和标距等数据完备且定义适用时，以代码计算工程应力或应变，保留单位、输入及处理范围。仅有力—位移截图且几何缺失时不换算强度或伸长率。应力—应变积分与力—位移积分的物理量不同，不能直接互称材料韧性。
- **异常与统计。** 打滑、夹口断裂、截顶和零点异常先列核查线索，不擅自删点或剔除试样。单条最佳曲线不能代表平均、显著改善或批次稳定性；有重复试样时按适用定义给出样本数与统计，缺失不编造。

## 证据 结论与交付

根据用户问题组织回答，开放分析应说明关键观察、相应方法、可比条件、解释依据和局限。复杂比较可列样品/指标/方法条件/观察/可支持结论；具体问题优先直接回答，不强制套表或附全部参数清单。

区分图片可见事实、报告明确数值、估读、计算结果和解释假设；报告数值与图片不一致时并列来源，不能静默择一。估读不超过图片分辨率给精度，图例不清不强配曲线。引用返回的页面 evidence_id 或 citation_url，不编造链接与来源。原始图片附件、页级证据和新会话历史由工作台保存。

补资料或复测建议只对准会改变本题结论的缺口，说明补充后能区分什么；缺条件时继续交付已支持的观察，并指出哪些结论暂不能成立。用户没有要求时不自动发起实验、预测或文件生成。

不能仅凭图像确定成分、身份、浓度、纯度、合格性、唯一配方或因果关系。适用标准和规格明确时可核对所提供结果，仍不代替正式质量审核与放行。不调用旧图谱聊天推理接口，不创建另一套分析会话。
