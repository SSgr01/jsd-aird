# 表格整理

读取源文件表头、工作表、原始行及业务字段字典，明确数据范围和输出目标。先列字段映射、含义、类型、单位、编号及对象组合主键；公司规则未提供时不自行建立正式编号。标识按文本保留前导零，日期确认格式和时区，空值不转为零。

复用 record-validation，使用 record_validate 检查缺项和同对象冲突，使用 quantity_check 做支持的同量纲单位换算。未知单位、字段含义不一致或跨量纲先列待确认。大表在原生沙箱可复核处理，记录处理行数、转换规则及未覆盖部分。

合并前确认匹配字段及唯一性。精确重复可以标记，同标识冲突保留所有版本；疑似重复只给候选，不自动合并。没有明确的冲突优先级不得默认取最新值或非空值覆盖。

交付整理结果、字段映射、缺项、重复冲突清单及来源行映射。仅用户要求时导出新文件，原始文件不覆盖；公司导出模板未知时使用通用表结构并说明。
