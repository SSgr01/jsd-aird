# 论文专利与技术路线比较

检索与原文读取复用 literature-review。先明确主题、时间语言范围、优先来源与收录排除条件，保留实际检索式和检索时间；配置为空时说明本次采用的范围，不谎称覆盖全部文献或专利。

每份资料按来源固定版本提取材料体系、方法步骤、工艺条件、检测方法、结果、局限及原文位置。读不到全文时仅标注摘要信息；涉及图与结构按平台证据读图流程处理，不能把未看图当已看。

在可比条件下比较路线；方法、单位、基材、温度或评价口径不同则分列，不直接排名。专利区分权利要求、说明书与实施例，公开内容不等于法律有效性或自由实施意见。只有真实内部路线依据才能作内部基准。

交付路线比较表、证据强弱、适用条件、局限和验证建议。数值换算使用代码，推断注明假设。不伪造法律状态或公司已采用结论；用户要求才保存报告。
