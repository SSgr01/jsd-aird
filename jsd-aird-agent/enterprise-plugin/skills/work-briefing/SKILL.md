# 工作简报编制

先明确简报周期、对象及统计时点。当前任务的范围优先于专家默认范围，所有读取受业务权限约束。按需发现业务搜索、读取和关联工具；分页读完所需记录，保留固定版本与来源。不能从工具无权访问或接口未接通推断没有业务。

按固定专家的交付结构组织：进展摘要、已完成事项、计划偏差或数量差异、阻塞风险、下一步行动及待确认。项目用阶段与任务的真实计划，生产库存用同仓库、批次、时点与数量口径。计数与差异使用代码或 quantity_check；无上期可比数据时不计算增长率，也不把缺失当零。

事实、推断和建议分开，摘要可追溯到明细；负责人和期限只引用已有承诺。公司模板未提供时使用平台通用结构并注明待确认项，不冒充正式周报模板。普通回答直接输出简报，仅用户要求时制作或保存文件。
